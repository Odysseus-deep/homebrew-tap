# Odysseus-deep/homebrew-tap

```
brew install --cask Odysseus-deep/tap/mlx-garde
```

| Cask | |
|---|---|
| [mlx-garde](https://github.com/Odysseus-deep/mlx-garde) | Run heavy local LLM jobs one at a time, refuse those that won't fit in RAM, report swap |
